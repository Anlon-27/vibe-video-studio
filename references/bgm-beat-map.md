转换函数，所有时间必须用它计算，禁止手抄近似值：

```js
const BPM = 112.90, BEAT = 60 / BPM, BAR = BEAT * 4, BAR0 = 0.228;
const bar = n => BAR0 + n * BAR;      // bar(0)=0.228, bar(8)=17.234
const beat = n => BAR0 + n * BEAT;    // 拍级微节奏
```

### 30fps 帧号

$$frame = \mathrm{round}\big((BAR0 + n \cdot BAR) \times 30\big)$$

| 1 小节 | 2.126 | 63.77 |
| 4 小节 | 8.503 | 255.09 |

## 3. 卡点层级（从强到弱）

1. **章节 / 大场景**：锁 8 小节乐句头（`bar 8 / 16 / 24 / 32 / 40 / 48 / 56 / 64 / 72`），至少锁 4 小节头。
2. **章节内揭示**：锁小节头（任意 `bar(n)`），例如硬币 `bar 30`、墓碑 `bar 34`、气体 `bar 38`、兰道尔 `bar 52`。
3. **字幕换行**：按拍计数，默认 6 拍（3.189s）；短句 4–5 拍；情绪句 8 拍。字幕入场比拍点晚 `0.25` 拍，淡入 `0.35s`。
4. **次级脉冲**：拍级 glitch、相机微震、数值跳动。
5. **纹理**：8 分音符只做 hat / 粒子闪烁，不做剪辑。

硬规则：

- 禁止在 8 分音符上切主画面。
- 禁止匀速转场；所有转场必须有加速度曲线。
- 每 8 小节至少一个大动作（换场、落卡、曲线延伸、镜头推拉）。
- 字幕起止必须落在拍网格上，不允许「看起来差不多」的手填时间。

## 6. 复用到新一期

1. 复制常量与 `bar/beat` 函数到 `config.js`，不要手写秒数。
2. 先定 7 个章节边界：`bar(8)`、`bar(11)`、`bar(24)`、`bar(44)`、`bar(56)`、`bar(71)`、`160.0`；再按内容量在 4 小节头上微调。
3. 章节内的揭示点用 `bar(n)`；字幕按 `beat(n)` 计数，默认 6 拍。
4. 渲染前跑配置自检（Node）：

```bash
node -e "
const fs=require('fs');
const src=fs.readFileSync('episodes/<slug>/config.js','utf8');
const {CFG,SUBTITLES,NOTES,SECTIONS,BAR,BAR0}=new Function(src+'\nreturn {CFG,SUBTITLES,NOTES,SECTIONS,BAR,BAR0};')();
const bar=n=>BAR0+n*BAR;
let prev=null,errs=[],gaps=[];
for(const [a,b,zh] of SUBTITLES){
  if(a<0||b>CFG.duration||b<=a) errs.push(['range',a,b,zh]);
  if(prev!==null&&Math.abs(a-prev)>1e-6&&a<CFG.duration) gaps.push(['gap',prev,a,zh]);
  prev=b;
}
for(const [t,label] of SECTIONS){
  if(t===0) continue;
  let d=1e9;
  for(let n=0;n<=Math.ceil((CFG.duration-BAR0)/BAR);n++) d=Math.min(d,Math.abs(t-(BAR0+n*BAR)));
  if(d>.001) errs.push(['section-off-bar',t,label]);
}
console.log('gaps（只允许标题卡留白）:',gaps);
console.log('errors:',errs.length?errs:'OK');
"
```

脚本会把 `gaps` 与 `errors` 分开输出：**唯一允许的 gap 是标题卡区间**，其余 gap 必须人工确认。`bar` 上限用 `(duration - BAR0) / BAR` 计算，不能写成 `duration / (BAR0 + BAR)`，否则末尾章节（如 `bar 71`）会被漏检。

5. 抽帧核对：至少检查每个章节头、drop、最后一个字幕句、淡出点。
6. 成片渲染后，用 `ffprobe` 确认 160.0s / 30fps，并对照本表抽 5–8 帧复核。
